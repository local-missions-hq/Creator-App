# Microsoft architecture icon sources

The SVG files in this directory are unmodified Microsoft architecture icons used only in the Local Missions technical architecture diagram.

- Azure service icons: Microsoft Azure Architecture Center, `Azure_Public_Service_Icons_V24.zip`, downloaded 2026-08-31 from <https://learn.microsoft.com/azure/architecture/icons/>
- Microsoft Entra ID icon: Microsoft Entra architecture icon package, downloaded 2026-08-31 from <https://learn.microsoft.com/entra/architecture/architecture-icons>

Microsoft permits these icons for architecture diagrams, training material, and documentation subject to the terms on those pages. Keep the product name beside each icon and do not crop, rotate, flip, distort, recolor, or use an icon to represent a non-Microsoft product.
