# Disposable workload PostgreSQL

Creates one candidate burstable PostgreSQL 16 Flexible Server, one application database, narrow public firewall rules, and one referenced Microsoft Entra administrator group. Password authentication and every administrator password field are absent. Automated point-in-time recovery uses bounded retention and no unapproved geo redundancy. Region, version, SKU, identity, collation, and price still require live review before a provider-backed plan.
